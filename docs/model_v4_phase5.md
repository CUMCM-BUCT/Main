# 阶段5：Q2/Q3流式候选运行器

范围仅为固定半径Q2/Q3，复用附录3参数、附件1线性插值及4小时后50℃/0.05延拓，初值28℃/2.55，R=0.02m。不生成Excel，不宣称候选计算通过收敛门禁。

`python scripts/run_q2q3_phase5.py --output data/processed/q2q3/probe --cells 20 --dt 60 --end 3600`

默认scan只保留当前完整ModelState（包括surface_moisture延续初猜），不保存时间历史。每个接受步检查中心、所有内部节点和半单元Robin表面的分段线性重构最大值；环境每分钟折点和4小时切换点强制落步。遇到首次端点穿越，从固定左接受检查点重新积分二分，返回满足阈值的右端点及括区，默认区间宽度≤0.01s。这只限制定位误差，不能代替PDE收敛，也不能排除大步内部的非单调穿越；须通过时间细化检查。

`--mode export`强制逐秒落步并流式写两个result2 CSV、每60秒result3水分CSV。按已有ExportContract从1秒/60秒开始；非整秒精确事件追加到两个结果，整点事件去重。截断到指定horizon且未达标时metadata明确标识，不能当完整结果。终点在metadata保留完整状态供后续诊断；所有CSV未舍入。

元数据包括附件hash、全部a_model源码和驱动hash、实际HEAD及dirty状态、数值设置、残差极值、拒步计数、运行耗时、最大值位置。运行中失败写failure类型和信息；输出均标candidate_only。运行时source_files_unchanged字段检查源码稳定性；dirty运行只能作为开发证据，后续正式结果必须从确定提交重跑。

建议分阶段计算：先N20/dt60全程粗事件及短程逐秒探针，估计成本；再固定dt做N20/40/80空间比较，固定N做dt60/30/15时间比较。除事件时间外需在共同物理时刻比较21点双场、中心/表面/全域最大和通量，若不单调则增加细化、尤其检查Robin支路。早期0–4小时独立用较小步长试验；必要时采用验证后的分段dt，不能由长期平稳阶段掩盖早期误差。暂未实现自动收敛矩阵和批准门禁，N20结果绝不是正式真值。

最后在选定网格进行逐秒export；与相同网格更细dt在早期和事件邻域比较，确认输出约束对积分及终点影响。现驱动直接逐秒积分，可能比scan昂贵；分块复算需要完整检查点和独立精度验证，尚未实现。Q4和敏感性均未开始。
