# 阶段5：Q2/Q3流式候选运行器与收敛筛查

范围仅为固定半径Q2/Q3，复用附录3参数、附件1线性插值及4小时后50℃/0.05延拓，初值28℃/2.55，R=0.02m。不生成Excel，不宣称候选计算通过收敛门禁。

`python scripts/run_q2q3_phase5.py --output data/processed/q2q3/probe --cells 20 --dt 60 --end 3600`

默认scan只保留当前完整ModelState（包括surface_moisture延续初猜），不保存时间历史。每个接受步检查中心、所有内部节点和半单元Robin表面的分段线性重构最大值；环境每分钟折点和4小时切换点强制落步。遇到首次端点穿越，从固定左接受检查点重新积分二分，返回满足阈值的右端点及括区，默认区间宽度≤0.01s。这只限制定位误差，不能代替PDE收敛，也不能排除大步内部的非单调穿越；须通过时间细化检查。

`--mode export`强制逐秒落步并流式写两个result2 CSV、每60秒result3水分CSV。按已有ExportContract从1秒/60秒开始；非整秒精确事件追加到两个结果，整点事件去重。截断到指定horizon且未达标时metadata明确标识，不能当完整结果。终点在metadata保留完整状态供后续诊断；所有CSV未舍入。

长导出按整秒分段持久化完整`ModelState`、各CSV已提交字节偏移和SHA-256。`--checkpoint-interval 3600`设置分段长度，意外中断后以同一参数加`--resume`校验输入、源码、设置和三个CSV前缀，再截去未提交尾部继续；`--stop-after-segments`仅用于可控暂停测试。已完成检查点重复`--resume`只重建缺失metadata，不重复数据行。分段边界不是Q3额外输出时刻。

元数据包括附件hash、全部a_model源码和驱动hash、实际HEAD及dirty状态、数值设置、残差极值、拒步计数、运行耗时、最大值位置。运行中失败写failure类型和信息；输出均标candidate_only。运行时source_files_unchanged字段检查源码稳定性；dirty运行只能作为开发证据，后续正式结果必须从确定提交重跑。

收敛筛查由以下驱动运行；每个算例保存共同物理时刻的21点双场、中心/表面/体积均值、全域最大值和边界通量，并记录事件时间、残差、最小含水量、Picard迭代及实际接受步长：

`python scripts/run_q2q3_convergence.py --output data/processed/q2q3/convergence_v1 --cells 20 40 80 --dt 60 30 15 --end 1200000 --sample 60 --workers 3`

比较前会校验样本文件哈希、数值设置、附件1哈希和全部相关源码哈希；来源或设置不一致的算例会被拒绝。报告固定标记`candidate_only`和`convergence_verified=false`，程序不具备把失败矩阵自动升级为正式结果的路径。

首批矩阵完成9/9个算例，事件时间从217621.8823s到855965.6396s；空间细化的含水率场、含水率统计量、湿通量和事件时间均未通过起始阈值。细化矩阵`convergence_refinement_v1`完成N=80/160/320、dt=60/30的6/6个算例，事件时间从207314.6777s到217809.2505s；即使N=160到320，最大含水率场差仍为约0.002175，事件时间差仍约1186s，继续不通过。两批运行的`q2q3_convergence.py`源码哈希不同，必须作为两组各自内部一致的候选证据解读，不能跨组拼接计算收敛阶。

因此本阶段尚未得到可用于正式`result2`、`result3`的网格/时间步组合。下一步必须继续空间和时间细化，并独立检查早期0–4小时及事件邻域；只有门禁通过后，才在选定网格执行逐秒正式导出和Excel模板写入。Q4和敏感性均未开始。
