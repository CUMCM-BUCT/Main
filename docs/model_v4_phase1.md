# A题 V4：阶段1固定约定

本阶段只固定输入、参数、单位、假设和输出契约，尚未实现或运行 PDE/FVM 求解器，因此不产生四问数值答案。

## 三个工况

- Q1：固定半径 0.02 m，附录2常热物性与非线性扩散系数。
- Q2/Q3：一次共享的固定半径模拟，全程使用附录3参数；Q2不是Q1的续算。
- Q4：独立从原始初值开始，使用附件2给定的比例径向收缩与附录4参数。

共同初值为 `T=28 degC`、`C=2.55 kg水/kg干物质`，长度 0.25 m。`h=25 W/(m²·K)`、`hm=8e-7 m/s`；后两套参数未另给边界系数，显式沿用附录2。温度场内部用摄氏度，只有 Arrhenius 指数先转换为 K。主模型不含潜热。

## H1-H6 与通量记号

以下内容是本仓库后续实现所依赖的完整闭合约定，不需要另查外部文档：

- H1：药材均质、各向同性、轴对称，径向传热传质占主导；忽略轴向非均匀和端面交换，圆柱长度固定为0.25 m。因此“全域达标”只表示一维径向模型的全域达标，不能未经二维端效应验证外推为实际有限圆柱每一点达标。
- H2：干物质无损。Q1-Q3固体骨架固定，干固体密度 `rho_d` 在空间上均匀。Q4初始 `rho_d` 均匀，材料作径向均匀比例收缩、长度不变，材料点满足 `r=xi*R(t)`，固体骨架速度为 `v_s=xi*dR/dt`。
- H3：`C` 为 `kg水/kg干物质`。定义规范化通量 `q_C=-D*grad(C)` 和物理水质量通量 `j_w=rho_d*q_C`，两者不得混用。`rho_d` 由干固体连续性决定；Q4比例径向收缩的雅可比 `J=(R/R0)^2`，满足 `rho_d(t)*J=rho_d0`。因为 `rho_d(t)` 空间均匀，统一密度尺度可在干基水分方程和归一化水量中约去；映射网格与材料同速后，材料坐标方程不再添加额外收缩对流项，也不把体积缩小误作干基含水率浓缩。若这些均匀或比例收缩条件失效，就必须恢复密度权重或相对速度项。
- H4：题给 `rho_g(C)*cp(C)` 只解释为有效体积热储存系数，不默认 `rho_g=rho_d*(1+C)`。主温度方程省略潜热、迁移水分携焓和形变做功，只能称有效热模型，不能称完整混合物焓模型。
- H5：附件1空气水分数值 `H_inf` 直接作为等效干基平衡含水率 `C_e` 的数值输入，并与题给 `hm` 配套；这是一项有效边界映射假设，不表示两种含水率的物理定义相同。
- H6：环境和半径按下一节的受控区间插值与尾部延拓处理；延拓不是实测事实，后续必须作为敏感性来源单独检查。

归一化总水量采用控制体权重对 `C` 积分，可不引入未知的绝对干物质量；任何 kg 单位水量平衡或潜热扩展仍必须使用 `j_w` 并给出一致的绝对质量基准。

## 输入策略

- 附件1：0至14400 s 范围内分段线性插值；更晚时刻使用 `T∞=50 degC`、`Ce=0.05`。接点允许小跳变。
- 附件2：0至259200 s 范围内分段线性插值，半径由 cm 转为 m；更晚时刻冻结为 `0.01198 m`。
- 原文件只读，加载时记录文件 SHA-256。PCHIP、末1 h均值和末点冻结等敏感性方案留到阶段7，不混入正式基准接口。

运行元数据按工况强制来源：Q1和Q2/Q3至少包含附件1，Q4同时包含附件1和附件2。Q1与Q2/Q3只记录固定半径0.02 m，不写入收缩策略；Q4才记录附件2线性插值及72 h后冻结。后续敏感性工况必须通过 `build_run_metadata` 的 `input_policy`、`geometry_policy` 参数显式替换默认策略，使记录与实际计算一致。

运行输入检查：

```powershell
$env:PYTHONPATH = "src"
python scripts/check_inputs.py
```

## 输出契约

- Q1：`result1.xlsx` 两表，1至1800 s逐秒，0至2 cm每0.1 cm。
- Q2：`result2.xlsx` 两表，从1 s逐秒导出至Q3事件终点；若事件不落在整数秒，追加精确终点。
- Q3：`result3.xlsx` 水分表，每60 s并追加精确事件终点。
- Q4：`result4.xlsx` 水分表，每60 s并追加精确事件终点；固定0至1.9 cm列，域外值为空，另设“药材表面”列。

Q1是固定终点契约，调用方只能请求1800 s；900、1800.5或1801 s等结束时间会直接报错，避免静默生成不完整或越界文件。

所有结果保留未舍入数据参与事件与守恒计算，Excel仅用数值格式 `0.0000` 显示。当前模块只定义采样规则，不写工作簿。
