# 当前版本代码包

打包时间：2026-09-12

本目录是当前工作区代码的可复现快照，保留原项目结构：

- `src/`：模型、有限体积离散、求解器、收敛分析与结果导出代码
- `scripts/`：运行、检查、收敛矩阵和 Excel 导出脚本
- `tests/`：单元测试与数值验证测试
- `docs/`：V4 模型约定、数值验证和阶段 5 说明
- `pyproject.toml`、`README.md`、`CONTRIBUTING.md`：项目配置与说明

未包含：`data/` 计算输入/输出数据、`deliverables/` 交付物、缓存、虚拟环境和 Git 元数据。

当前正式收敛计算使用的关键参数仍记录在运行脚本和输出目录中：

- 表面加密网格：`grading_exponent=2`
- 当前正在推进的算例：`N640_dt1p875_grade2`
- 当前代码仍支持 `grading_exponent=1` 的均匀网格
