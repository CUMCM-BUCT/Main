# Main 代码版本归档

本目录按项目演进保存三个可独立查看的代码快照。每个子目录均来自对应 Git 提交，保留当时的源码、脚本、测试、文档和项目配置；未包含运行数据、缓存和交付结果。

| 版本 | Git 提交 | 说明 |
|---|---|---|
| [最初的详细版](./最初的详细版) | `5c5359a` | V4 模型、统一径向 FVM/非线性求解器，以及 Q1 阶段 4 严格验证 |
| [详细版中途的快捷版](./详细版中途的快捷版) | `4bdea30` | 在详细版基础上加入 Q2/Q3 流式推进、事件定位和快速候选计算 |
| [极速版](./极速版) | `55409ae` | 可恢复的 Q2/Q3 收敛流水线、Richardson 快速导出和原子写入 |

说明：版本名称是按工作流程命名的；“快捷版”并非替换 V4 方程，而是减少输出和验证范围以便快速得到候选结果；“极速版”仍沿用同一模型体系，只增加数值收敛与导出自动化。
