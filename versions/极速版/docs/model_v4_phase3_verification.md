## 验证实现

验证入口为 `tests/test_verification.py`。解析常系数验证只通过 `a_model.fvm` 的公开接口组装并推进；Q4 端到端探针另通过 `CoupledRadialSolver` 验证完整耦合路径。解析 Bessel 函数、特征根二分和解析级数均由 Python 标准库实现，不依赖 SciPy 或 mpmath，因此 `pyproject.toml` 无需增加测试依赖。

Dirichlet 与 Robin 测试均取归一化半径、扩散率和储存系数为 1，在 `Fo=0.1` 比较 `N=20,40,80`。各网格使用 `N²` 个 Backward-Euler 步，即 `ΔFo=0.1/N²`，使时间误差与空间误差同为二阶量级。原始数值未知量与解析解在同一环形控制体内的 `2ξ` 加权平均比较；表面值只与 Robin 半单元重构比较；总体平均均使用 FVM 权重 `w_i`。解析级数保留 7 个模态，在该 Fourier 数下末端模态已远低于报告误差。

## 6. Q4 比例收缩、零通量 72 h：两层证据

### 6.1 完整耦合求解器端到端探针

用 `CoupledRadialSolver("q4", ...)`、`N=12` 和确定性记录型半径提供器完成 144 个 1800 s 步。初始温度/含水率与恒定环境相等，因此物性仍由真实 Q4 参数函数计算，但热、水外通量均为零。

- 144 个新时间层均恰好查询一次半径，查询序列为 1800 s 至 259200 s；
- 最终诊断半径恰为 `0.01198 m`；
- 全历程最大温度漂移：`1.953993e-13`；
- 全历程最大干基含水率漂移：`3.552714e-15`；
- 最终加权干基平均误差：`1.332268e-15`。

错误的体积浓缩式会给出 `C0(R0/R)^2=7.107004`，而耦合末态仍为 `2.55`，两者相差 `4.557004`。这条探针覆盖 Q4 参数、边界重构、Picard、时层半径查询和 72 h 积分路径。

### 6.2 移动半径空间核、守恒与扩散时钟

先保留 `D=0` 的直接材料坐标不变量检查。固定材料网格 `N=40`，以 1800 s 步长将半径从 `0.02000 m` 线性缩至 `0.01198 m`，表面通量为零；使用材料控制体权重 `w_i`，不用当前体积乘 `C`：

- 72 h 内最大逐单元干基含水率漂移：`0.0`；
- 末态加权干基含水率总量误差：`0.0`。

结果满足 `< 1e-10`，且没有把几何体积缩小误写成干基含水率浓缩项。

再取非均匀正场、`D=1e-10 m²/s` 和零 Robin 通量，通过生产 `freeze_operator`、`assemble_backward_euler`、`solve_tridiagonal` 接口逐步推进。移动半径解与单位半径下按每步 `ΔFo=D Δt/R_{n+1}²` 推进的离散时钟参考逐层比较：

- 几何扩散时钟 `ΣΔt/R_{n+1}² = 1.085831520e9 s/m²`，对应 `Fo=0.108583152`；
- 固定初始半径 mutation 的时钟仅为 `6.480000000e8 s/m²`，对应 `Fo=0.0648`；
- 移动半径与逐步时钟参考的最大差：`1.776357e-15`；
- 移动半径加权总量误差：`8.881784e-16`；
- 错误固定半径 mutation 与正确末态最大差：`6.800102e-2`，显著大于 `1e-4` 门槛。

因此测试不仅验证零通量守恒，也能在 `R(t)` 被错误冻结或忽略时失败。

## 结论与剩余风险

六类验证均通过阶段 3 门槛，且 Dirichlet/Robin 原始未知量确实按控制体平均比较。当前证据验证的是常系数离散、半单元 Robin 边界、守恒权重及材料坐标不变量；它不替代后续正式变物性 Picard 收敛、真实输入插值、Q1 早期时间步加密、事件定位或 Excel 契约验证。由于 BE 为一阶时间格式，本阶段令 `ΔFo∝N^-2` 得到的联合二阶收敛不能被解释为固定网格下的二阶时间精度。
